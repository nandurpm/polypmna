# UI Primitives

## Purpose

Contains the reusable Radix/shadcn-style building blocks used by route and product components.

## Contents

- Form controls, overlays, navigation, data-display, feedback, and layout primitives are each implemented in a focused file.
- `index.ts` provides selected stable re-exports.

## Responsibilities

Generic presentation primitives belong here; domain-specific student or AI behavior belongs in parent components/pages.

## Important Notes

Keep primitives theme-token based, responsive, accessible, and compatible with light and dark modes.
